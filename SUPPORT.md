# Getting help

- **A question about using Splint,** or an idea: ask in [Discussions](https://github.com/nennovate/splint/discussions).
- **Something broken:** open an issue with the bug form.
- **A vulnerability:** report it privately, as [SECURITY.md](SECURITY.md) says, never in a public issue.

[Getting started](docs/getting-started.md) and [how it works](docs/how-it-works.md) answer most questions about setting up and what Splint does. For anything else, replies can take some time.
