# Roadmap

Each step ends in something that runs.

**Next goal: v0.** Real owners complete useful interactions through a host we run, and real agents have shown it works. Owners come first and use it for free, because the network has little value of its own yet. The v0 milestone is reached when all its issues are closed, with the validation checklist last. v1 follows.

The repository has been public since 2026-11-22, and `v0.1.0` is its first release, for anyone to try. That's a version number and not the v0 goal: 0.x says anything may still change.

1. **Two agents exchange a signed message.** Done, on one machine with scripted and real agents and software keys. Run it with `make e2e` or `make agents`.
2. **Managed requests.** Done, on one machine with scripted agents and software keys, with owners signing through the `owner-key` tool. Any type of interaction runs on one chain, from a small schema, with signed state that a host can't forge. Two agents agree a type in conversation, with `type/1`, named by the fingerprint of its schema, with no owner signing and nothing installed; core has a plain conversation of its own. The examples are a meeting, a time, a quote, a document request and an RSVP. Once a deal with a price is completed, the side it pays asks to be paid the agreed amount at a place its owner signed, and says when it arrived, with Splint holding no money, and every approval with an amount says who pays whom in fixed words: built, provisional, and run by `sim/payments.py` in `make e2e`. Run it with `make trace`.
3. **Rules that hold when an agent is fooled.** Owner keys, bindings, signed rules, contact rules, quarantine, invitations, per-agent limits, the owner's reach setting and permission levels are done, in `make e2e`, with software keys. So are the owner's `text` per contact with a daily cap on words, and a general grant record with a check any resource can call. So is holding up against modified hosts and Signets working together, in `sim/colluders.py`, and against a stolen owner key, in `sim/key_safety.py`. `splint setup` won't put the owner key where an agent running as the same user could read it unless the owner says so, and warns each time it's there. Agents connect through an MCP adapter or plain HTTP.
4. **Usable by an owner.** Install, agent connection and a small owner page are done: `splint page`, shown in a real browser on one machine. So is an agent joining on its own from a host's address and working at once, before its person has set up their controls, the owner's page and terminal commands for an agent on another device, and `splint auto` signing what an owner's level allows. So is a one-use link: someone with no account and no agent answers a typed request on a page, and the owner gets a signed result. Addresses are `name~domain` in one spelling, with an owner part only its owner can sign for. So are invites over Splint: an agent invites another by address or contact card, the other accepts, and each owner's side signs the contact in, with nobody handling an ID, in `sim/invites.py` and `sim/agent_join.py`. So is open signup by default on hosts that `deploy/` and `splint host start` set up, with limits per network, handles nobody can pass for the host with, and agents nobody used let go after 30 days with their handle kept, in `sim/agent_signup.py` and `sim/agent_join.py`. So is "your controls", the owner page on the person's own computer: `splint controls HOST` serves it at `http://localhost:7480/owner`, signed with the computer's own sign-in and no host in it, with a recovery code shown once, each agent and what needs the person on one page, unlocked once a visit so approvals, people held and settings sign as they're made, and one look shared by every page a person sees, in `sim/owner_controls.py`, `sim/owner_page_here.py` and `sim/agent_asks.py`; served alone with `--port`, it makes no passkey. Hosts serve no owner page and no pairing codes: Nenye decided on 2026-11-21 that owners sign only on their own computers (issue 635). The connectors for Claude Code, Cursor and any agent with a shell, `agents.md` and the MCP tools give each agent what controls are, `computer_link`, the install lines for a Mac, Linux and Windows, and guidelines, never words to say. Fewer confirmations, warnings and load protection, from Nenye's v0 decisions of 2026-11-14, are done: Drop comes chosen for contacts the agent added, with Keep one click away, a contact's new key from its own owner carries on and tells the owner, invites between one owner's agents accept themselves, a buyer's one yes covers their own confirm, Signet's own facts and warnings beside each arrival, batched wakes, tighter limits for contacts the agent adds, and who kept the agent busy on the owner's pages. `splint`, Signet and `splint-owner-key` build for Windows on x86_64 and Arm, as a preview, with Signet and Splint on the computer each on a named pipe only its user can open, no task at login until the Windows builds are code-signed, as Defender quarantined unsigned programs that started at login (issue 1138), so the next `splint` command that needs it after a sign-out or a restart starts again what was running, and `install.ps1`, whose `controls HOST` sets up a person's controls on their own Windows computer. CI lints them and runs their unit tests on Windows for every pull request. It passed there on 2026-11-15 and hasn't run since, so what changed after that is checked by cross-compiling only, and none has run end to end on a real Windows machine. Next: the public release, and later a phone app for owners with no computer.
5. **Real agents do the job.** Temporary agents set up as owners' assistants run it repeatedly, including one non-Claude agent (Codex over plain HTTP has done the quote job), while a fully fooled agent tries to break the rules.
6. **A live host.** Two real servers run it over verified TLS, and survive crashes, reboots and a restore, in `sim/live_hosts.py`. Backups are encrypted to a key kept off the server, and root can't log in. Next: the owner's own domain and backups copied off the server.
7. **Real owners.** About 3 pairs use it on real work. v0 is reached once they come back without being prompted.

One owner ID with a sign-in per device: reading and checking an ID's added and removed sign-ins, each proving it holds its key, is done in core, the Go verifier and the page, with shared vectors, and hosts and Signets take a newer copy and end what a removed key signed. Sign-ins made as passkeys at a host's page before 2026-11-21 still verify, though none can be made or used now, a recovery code can be set after the ID is made, the reading key belongs to the ID with a locked copy per sign-in, and a contact asks about a move a new sign-in signed. Next: the add-device screens, secure-chip keys on computers, and `owner-key` adding one.

Sign-up (v0 plan, built): an agent's `splint controls` always gives it `computer_link` to hand over, wherever it runs, which opens on Splint on the person's computer, and the agent guides them through installing Splint there where it isn't yet. Where its person uses that computer it's also one touch on Splint there, whose owner page signs with the computer's sign-in in its chip or a locked key file and keeps sessions as the viewing setting allows; a controls link lasts an hour, and the agent takes up the answer by its own key. There are no pairing codes. The recovery code is set later from a reminder on every page. Agents ask for settings, held steps, with who pays whom in the prompt, and where their person gets paid, in the same one-approval flow, and a person at a terminal gets the page's warnings. Every v0 piece is on `main`, and `make check` runs it end to end with scripted agents, key files for sign-ins, and a real Chrome, in `sim/agent_asks.py`, `sim/asked_by_link.py`, `sim/agent_signup.py`, `sim/agent_join.py`, `sim/owner_controls.py` and `sim/owner_page_here.py`. Not yet run: the Touch ID path, by hand on a real Mac, the owner page in Safari and Firefox, and anything end to end on Windows.

Later than v0: hardware-held keys, a second computer, the iPhone, the email bridge, the full control center, paid hosting, the shared log, reputation, and payment refunds, deposits and mandates.

**Checks before v0:** a security read attacking real hosts and Signets, a crypto read by a second model that didn't write the code, a second verifier in Go written from the protocol alone that agrees with all 1,071 shared vectors it has a check for, of the 1,385 Splint's own code runs, and Wycheproof's 262 ECDSA P-256 vectors run against Splint's own signature check in `make check`, with no disagreements.

Formats can still change until 1.0, when Nenye freezes them.
