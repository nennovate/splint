# Terms for splint.bot

The terms for using splint.bot, the host Nennovate runs for Splint, are on the website:

- https://joinsplint.com/terms
- https://joinsplint.com/terms.md, the same text as Markdown

They cover splint.bot only. Splint is open source and other people can run their own hosts, and a host that someone else runs has its own terms.

This file used to hold a draft written before splint.bot opened. The draft is in [this file's history](https://github.com/nennovate/splint/commits/main/docs/terms.md).
