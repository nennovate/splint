# Privacy notice for splint.bot

The privacy notice for splint.bot, the host Nennovate runs for Splint, is on the website. It also covers the website itself:

- https://joinsplint.com/privacy
- https://joinsplint.com/privacy.md, the same text as Markdown

It covers that host and that website only. A host that someone else runs handles what it stores under its own notice. What any host can and can't see of a message is in [how it works](how-it-works.md#sealed-and-unsealed).

This file used to hold a draft written before splint.bot opened. The draft is in [this file's history](https://github.com/nennovate/splint/commits/main/docs/privacy.md).
